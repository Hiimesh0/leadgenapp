## 🛠️ How to Customize

- **Company Information:** Update `src/data/company.ts` to change contact details, founder bio, or links across the entire website.
- **Services:** Edit `src/data/services.ts` to add or update service offerings.
- **Industries:** Edit `src/data/industries.ts` to tailor industry descriptions and feature lists.
- **Pricing:** Edit `src/data/pricing.ts` to modify package names, fees, delivery schedules, or features.
- **Portfolio Projects:** Add new live client projects in `src/data/portfolio.ts`.
- **FAQs:** Add or modify frequently asked questions in `src/data/faqs.ts`.
