## 2. In-Scope Deliverables (Strict Boundary)
The Enterprise Plan Agent coordinates bespoke enterprise requirements:
1. **Multi-Location / Multi-Branch Architecture:**
   - Single overarching brand portal with dynamic branch selector (e.g. Surat, Ahmedabad, Vadodara).
   - Location-specific doctor rosters, consultation hours, and address routes.
   - Centralized master dashboard with role-based branch manager permissions.
2. **Advanced Backend & API Integrations:**
   - Bi-directional sync with existing Electronic Medical Record (EMR) or Hospital Information Systems (HIS).
   - Custom payment gateway integrations (Razorpay, PayU, Stripe) for booking deposit collection.
   - Multi-tenant cloud architecture with complete data isolation per hospital unit.
3. **Advanced WhatsApp Automation & Multi-Agent Triage:**
   - Multi-agent WhatsApp gateway routing incoming messages to specific branch coordinators based on location keywords.
   - Automated post-consultation feedback collection and Google Review generation engine.
   - Bulk clinic patient re-engagement outreach with regulatory compliance, rate limiting, and unsubscribe handling.
4. **Custom Deployment & Cloud Sovereignty:**
   - Deployment options for dedicated VPS, AWS, GCP, or multi-region Render infrastructure.
   - Dedicated PostgreSQL / Redis clusters with automated failover and daily encrypted off-site backups.
5. **Stringent Healthcare Security & Auditing:**
   - Comprehensive audit logging for every administrative touchpoint and data access event.
   - Role-Based Access Control (RBAC: Super Admin, Branch Admin, Front Desk, Doctor, Auditor).
   - Data retention policies and privacy-first patient anonymization.
