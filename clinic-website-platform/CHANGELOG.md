## [1.0.0] - 2026-11-05
### Added
- **Multi-Agent Governance:** Established `AGENTS.md` operating constitution with 4 Plan Agents and 14 Specialist Agents.
- **Modular Directory Architecture:** Structured `clinic-website-platform/` with decoupled services, platform control plane, and client sandboxes.
- **Cloud Provider Abstraction:** Designed generic deployment adapters enabling migration from Render to VPS/AWS.
- **WhatsApp WAHA Integration:** Containerized WAHA setup with WebJS engine, automated QR recovery, and appointment confirmation dispatches.
- **Autonomous Image Pipeline:** Formulated WhatsApp image-to-website update workflow with 4 safety automation modes.
- **Comprehensive Documentation Suite:** Formulated Business Plan, Pricing Matrix, Architecture, API specs, Database Schema, and Recovery guides.
- **100% Free-Tier Cloud Blueprint:** Prepared `render.yaml` with ₹0/month budget compliance.
