## 🌟 Overview

**LeadGenApp (DigiBoost Gujarat)** is a comprehensive, production-grade digital platform and multi-agent business execution system created to help small and medium enterprises (SMBs) in Gujarat establish a world-class online presence, automate customer inquiries, and capture high-intent leads.

Built using 100% free, modern open-source web technologies and AI workflows, the platform delivers:
- **Ultra-Fast Mobile-First Websites:** Optimized for Indian 4G/5G mobile browsing habits.
- **WhatsApp Concierge Automation:** 1-click lead capture directly connecting prospects to business reception.
- **Conversion-Optimized Portals:** Form validation, instant appointment requests, and transparent service tiers.
- **Flagship Industry Demonstrations:** Full interactive clinic showcase featuring before/after cosmetic smile transformation sliders.

## 🛠️ Local Development & Preview

No build tools are required for the main agency website—it runs entirely on semantic HTML5, modern CSS3, and vanilla ES6:

1. Clone the repository:
   ```bash
   git clone https://github.com/Hiimesh0/leadgenapp.git
   ```
2. Open `index.html` directly in your browser.
3. For the React/TypeScript dental demo:
   ```bash
   cd demos/him
   pnpm install
   pnpm dev
   ```
