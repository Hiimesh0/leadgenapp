## 🚀 STEP-BY-STEP FREE DEPLOYMENT (GITHUB PAGES)

You do **not** need to pay for web hosting. GitHub Pages provides 100% free, SSL-secured (HTTPS), ultra-fast global hosting.

### Method 1: Deploying via GitHub Web Interface (5 Minutes)
1. Go to [GitHub.com](https://github.com) and create a free account (if you don't have one).
2. Click **New Repository** → Name it `digiboost-gujarat` (or your company name).
3. Set the repository to **Public**.
4. Upload all files from `website/source_code/` into the root or a `public/` directory, and keep `assets/` linked at the same relative path.
5. In your GitHub repository, click **Settings** (top right gear icon) → **Pages** (left sidebar).
6. Under **Branch**, select `main` (or `master`) and folder `/ (root)` → Click **Save**.
7. Within 60 seconds, GitHub will generate your live URL:  
   `https://<your-username>.github.io/digiboost-gujarat/`

### Method 2: Testing Locally on Your Windows Computer
1. Open File Explorer and navigate to `c:\Users\kanth\Desktop\business\AI-1-CRORE-MISSION\website\source_code\`.
2. Double-click `index.html`. It will instantly launch in Google Chrome, Edge, or Firefox.
3. No server or terminal commands required — pure client-side code!

## 📩 CONNECTING THE LEAD CAPTURE FORM (100% FREE)

Currently, `contact.html` validates submissions locally. To have submissions emailed directly to your inbox for free:

1. Visit [Formspree.io](https://formspree.io) or [Web3Forms.com](https://web3forms.com) (both have generous free tiers: 50–250 submissions/month).
2. Create a free form and copy your Form ID/Access Key.
3. In `contact.html`, set `<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">`.
4. Now, every time a Gujarat business owner submits a lead, you instantly receive an email alert on your phone.

## 🌐 CONNECTING A CUSTOM DOMAIN (OPTIONAL ₹800/YEAR)

When you are ready to use a custom `.com` or `.in` domain:
1. Buy `digiboostgujarat.in` or similar on Namecheap or GoDaddy (~₹499–₹899 for year 1).
2. In GitHub Repository → **Settings** → **Pages** → **Custom domain** → Enter your domain.
3. Add the CNAME / A records in your DNS provider as instructed by GitHub. Free automatic SSL certificate provided!
