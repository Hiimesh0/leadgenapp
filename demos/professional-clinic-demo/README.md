## 💎 Features Included (Professional Plan)

1. **7 Core Static Pages:**
   - `/` — Engaging Homepage with Trust Pillars, Service Previews, Clinician Highlights, and Lightbox Gallery.
   - `/#/about` — Clinic Story, Sterilization Standards, and Clinical Philosophy.
   - `/#/services` — 6 Comprehensive Treatments (Digital Smile Makeover, Ceramic Veneers, Clear Aligners, Laser Whitening, Single-Visit Restorations, Preventive Wellness) with category filters and procedure FAQs.
   - `/#/doctors` — Detailed Doctor Profiles, Post-Graduate Credentials, Clinical Philosophy, and Direct Consultation Scheduling.
   - `/#/gallery` — Categorized High-Definition Tour (Lounge, Operatory Suites, Hygiene Hub) with interactive Lightbox Modal.
   - `/#/contact` — Complete Contact Coordinates, Timings, Interactive Location Card, Direct WhatsApp Desk, and Enquiry Form.
   - `/#/appointment` — Dedicated Interactive Intake Flow with Client-Side Validation, Slot Selection, Unique Reference Generation (`APT-2026-XXXX`), and One-Click WhatsApp Confirmation.

2. **UX & Design System:**
   - **Colors:** Deep Medical Teal (`#123C3A`), Sage Green (`#2F6F68`), Soft Mint Accent (`#B7D8C9`), Clean Sand Background (`#F7F8F5`).
   - **Typography:** Playfair Display (Serif Headings) & Plus Jakarta Sans (Modern Body).
   - **Floating WhatsApp Button:** Fixed floating pill for instant conversion.
   - **Unobtrusive Demo Banner:** Clear concept labeling to comply with advertising regulations.

3. **Architecture:**
   - Pure Static (Zero Backend / Zero Database cost).
   - React 19 + TypeScript + Vite 6 + Tailwind CSS.
   - Relative asset routing (`base: './'`) and `HashRouter` ensuring 0 broken links or 404s on GitHub Pages.

## 🚀 Deployment to GitHub Pages

1. Navigate to **Settings** > **Pages** in this repository (`Hiimesh0/Busns`).
2. Under **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `root`
3. Click **Save**.
4. Live site URL: `https://hiimesh0.github.io/Busns/`
